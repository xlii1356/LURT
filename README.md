# LURT 
Lancer Ultimate Reaction Tracker

## Features:
 - Import a standard COMPCON pilot Json file to load all reactions from your talents and core bonuses, as well as systems, weapons, and frame traits from your active mech
    - Includes reactions not flagged in COMPCON, such as the Saladin's Warp Shield and Hydra Orochi drones
 - Automatically combines the number of uses per round for duplicate systems
 - Tracks unlimited uses, 1/round or x/round intuitively, and resets all when you hit Next Round
    - 1/misson and 1/ scene reactions are not recovered when hitting next round 
 - Simple drag and drop reordering, and right click support to edit, reset, or delete
 - Dynamic text wrapping for window resizing, as well as text size control
 - Toggable mini mode and "always on top" mode for a Widget feel while in your VTT of choice
 - 4 compcon inspired color schemes (Gms Red, Horus Green, MSMC Teal, and Harrison violet)
